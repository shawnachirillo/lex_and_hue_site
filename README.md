# Lex & Hue Dynamic Concept

A complete Next.js App Router concept using Tailwind CSS and Framer Motion.

## Run

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Included
- Responsive navigation + mobile menu
- Synchronized rotating orange hero word and hero visual
- Parallax hero motion
- Editorial typography and asymmetrical layout
- Animated manifesto section
- Large case-study storytelling blocks
- Scroll-triggered reveal animations
- Accordion services
- Sticky process section
- Animated orange CTA
- Reduced-motion support

Replace the abstract case-study artwork with your real project images when ready.
